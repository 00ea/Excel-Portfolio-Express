# **Excel's Portfolio (Express Version)**

This website is essentially a digital embodiment of me, Excel Aibangbee, but using ExpressJS and NodeJS. In the previous version, I was tasked with using just HTML and CSS to build my site. With this updated version, I used ExpressJS to generate a template for which I built my site upon. I put a lot of effort into making this an engaging experience for all that wish to learn more about my life and journey in a way that's captivating.
